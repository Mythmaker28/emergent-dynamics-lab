## Why this test exists

two missing objects. DOTC01 has derived both:

- **A** — a daughter centre whose identity is not one Y molecule: `FUNCTIONAL_CONTINUITY_ACROSS_CONSTITUENT_TURNOVER`.
- **B** — an observation criterion matched to the organiser timescale: an **event-based** hold rather than a clock.

And it found the phenomenon already present in surviving developmental data: **4 centres in 4 of 44
PQEC01 B1 worlds complete a constituent turnover inside one continuous identity interval, and 3 of them

Those 3 are a **post-outcome developmental diagnostic**, found by searching data that already existed.
The whole content of this successor is to fix the criterion *before* the worlds exist, so the events
cannot be found by searching.

## The eight required elements

### 1. One operational daughter-organiser object

A **centre** is a time-indexed connected component of Y-occupied cells under the frozen classifier:
toroidal single-linkage with adjacency distance `<= CORE_R = 5.0`.

**Centre identity across steps** is a mutual-unique nearest-centroid match within `CORE_R`. A tie, a
fission or a merger **ends** the identity interval and is never absorbed into it. This is what keeps
centre *creation* structurally separate from centre *turnover*.

No parent-child genealogy between Y molecules is invented, asserted or required. The engine keeps no Y
tracker and this test must not create one.

### 2. One exact constituent-turnover event

`COMPLETE_TURNOVER` on one continuous identity interval requires all of:

1. the component stays spatially coherent under the frozen rule throughout;
2. `N_Y_C(t) >= 1` at every step — the component is never empty;
3. at least one **Y removal** recorded inside the component (a decay event in the `ydeath` ledger);
4. at least one **accepted Y birth** recorded inside the component (`ybirth` ledger);
5. both events inside that one interval.

**Theorem, proved in DOTC01 and confirmed by the data.** A centre holding one constituent can reach
complete turnover only through `BIRTH_THEN_DEATH`: if the single constituent decays the component is
empty and condition 2 fails. `DEATH_THEN_BIRTH` requires `N_Y_C >= 2` before the removal. The one
observed `DEATH_THEN_BIRTH` case had `N_Y = 2` at the removal step, exactly as the theorem requires.

**Emigration is not a removal.** For a one-cell component the component travels with its own Y, so a hop
can never remove that Y from its own component; once there are two or more constituents, one moving
beyond `CORE_R` creates a *second component*, which is creation, not turnover. Record emigration
separately and never count it as turnover.

### 3. One functional-continuity measure

`FUNCTIONAL_CONTINUITY_MEASURE = ACTIVE_LOCAL_X_PRODUCTION`.

Accepted new X births inside the centre's own cells, on **both sides** of the removal event. Inherited X
cannot create a birth event; this is FMRT01's causal lesson, established with a matched no-source arm
that produced exactly zero daughter-disc X births in 22 of 22 blocks.

**Zero is the only threshold, and it is not a choice** — it is the value the matched no-source control
takes. No absolute local mass threshold is used. No world-total quantity may enter.

Note the measure is exactly readable: `kX = 1.0`, so at any Y-occupied cell holding at least one X the
X-birth probability is `min(1, kX*nX*nY) = 1` and the birth count is exactly `min(nSX, free)`. Local X
production is deterministic given the recorded environment.

### 4. One horizon

`T_HORIZON = 11000`, unchanged. The hold is **event-based** — the centre must carry its local X function
through at least one complete turnover — and the horizon only bounds the observation.

The horizon is **not lengthened**. The model median complete-turnover time lies beyond 11000, so a longer
horizon would raise the rate; DOTC01 §7 forbids going past 11000 without a separate justification and
cost analysis, and 11000 is already decision-capable at the sample size below.

### 5. One executable parameter point

**B1**: `kY = 2.5118864315095822e-05`, `muY = 9.261187281287937e-05`, with every inherited constant
unchanged. No sweep, no interpolation, no second point.

B2 is excluded structurally, not statistically: at `muY = 1e-08` a constituent removal has probability
`1.0999e-04` over the entire horizon, and the ledgers confirm **zero** Y deaths across 44 worlds and
11000 steps each. A removal is a necessary part of the turnover definition, so B2 cannot supply one.

### 6. One exact primary endpoint

Per seeded world, a binary: **does at least one continuously matched centre satisfy
`FUNCTIONAL_CONTINUITY_ACROSS_CONSTITUENT_TURNOVER`** under the criterion above?

The independent unit is the **seeded world**, as throughout this programme.

### 7. One exact null

```
H0 : p <= 0
H1 : p >  0
one-sided alpha 0.05,  critical count = 1
```

Zero is not a chosen threshold. Under the hypothesis that a centre's identity **cannot** survive removal
of a constituent, a removal necessarily ends the identity interval, so a birth and a removal can never
lie inside one interval and the event probability is exactly zero.

**State this honestly in the final report:** with `p0 = 0` a single qualifying event rejects, so the
value of this test is not statistical power. Its value is **prospective freezing**. Do not dress it up
as a powerful test.

### No matched causal fork

DOTC01 §14 prefers a fork only if parent-removal causality is load-bearing. For establishing that a
centre carries organiser-level identity through turnover it is not: the question is about the centre
itself. The fork belongs to the **subsequent** question and its budget is deliberately not spent here.
