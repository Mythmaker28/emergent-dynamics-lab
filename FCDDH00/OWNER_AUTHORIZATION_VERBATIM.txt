6.4 Allocation-orbit uniformity diagnostic
The primary x[b] is allocation-averaged and exactly invariant. To determinewhether the effect is uniform rather than carried by one neutral member, usethe fixed axis v to compute all four cross-orbit differences:
p[b,aN,aF;v] = dot(v, d[b,NEAR,aN] - d[b,FAR,aF])
u[b;v] = min_(aN,aF in {0,1}) p[b,aN,aF;v]
A_PAIR[b,aN,aF] = sqrt(2) * (
    TAU[b,NEAR,aN] + TAU[b,FAR,aF]
)
u>0 means every NEAR allocation member lies above every FAR allocation memberalong the fixed carrier-differential axis. It is invariant to independentallocation-member relabellings. This is deliberately stronger than theallocation-averaged interaction.
The displayed A_PAIR follows because each pair contrast contains four rowresponses with absolute coefficient 1/sqrt(2). Derive and certify it from theexact parent coefficient map before outcomes; transform the vector and boundtogether if the committed normalization differs.
Define one conservative, orbit-invariant block success:
J[b;v] = 1 iff for all four (aN,aF):
    lower(p[b,aN,aF;v]) > upper(A_PAIR[b,aN,aF])
m[b;v] = min_(aN,aF) (
    lower(p[b,aN,aF;v]) - upper(A_PAIR[b,aN,aF])
)
An unresolved interval, equality or one failing allocation pairing givesJ=0. This is simultaneously directional, response-material and robust to theunanchored allocation orbit. J=1 exactly when the certified m>0. It is notthe same as the less demanding averaged interaction.
