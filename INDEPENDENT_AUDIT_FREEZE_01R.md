## Frozen evidence programme

### A. Chain and provenance

- Verify ancestry `ETPC -> EEFCA -> ETNBFC -> ETCMNFC` from commit parents.
- Record exact commit identities, authored/committed times and commit messages only after this freeze.
- For each allowed experiment prefix, identify protocols, reports, verifiers, hash manifests and DEV artefacts from
  commit-local name metadata. Reject and do not open any path tripping the graded-access sentinel.
- Recompute blob hashes and verify that every report/result is bound to the code/protocol it claims.
- Compare local refs, remote refs, GitHub branches/commits/PRs/releases and workflow publication behaviour.

### B. Operator audit

- Read operator definitions and their units, sign conventions, orientation conventions, boundary conventions,
  normalizations and declared domain.
- Reimplement each scalar reduction independently from the specification, without importing repository code.
- On allowed toy and DEV arrays only, compare implementation and independent reduction in float64 using
  `abs(error) <= 1e-12 + 1e-10*abs(reference)` where a scalar reference is meaningful.
- Test orientation reversal, global sign reversal, permutation of records, duplicated/missing rows, zero fields,
  nonfinite values, boundary-only support and minimally nonzero support.
- Keep every operator separate. Do not construct a composite score.

### C. Oracle audit

- Enumerate every PASS/FAIL gate and its input dependency.
- Prove each gate can fail with a minimally edited synthetic or copied DEV fixture; never mutate the source blob.
- Verify the oracle rejects hash tampering, malformed schema, missing evidence, contradictory counts, extra rows,
  nonfinite values and report/result disagreement.
- Detect fixture-keyed, filename-keyed, expected-value-keyed or self-referential tests.
- A test that only checks that stored expected values equal themselves is classified `FAKE_PASS`.

### D. Endpoint reconstruction

- Recompute enrolment, exclusion and denominators from allowed raw DEV artefacts.
- Recompute every reported 60/60-type count and its exact dependency graph.
- Check whether any eligibility condition is downstream of the measured outcome, whether failures are silently
  excluded, and whether operator nonzero is tautological under eligibility.
- Separate endpoint existence, endpoint congruence, topology, transport, boundary flux, minimality and causal
  attribution. A pass on one axis never supplies another.

### E. Inference red team

- Search for alternative explanations consistent with all audited observables: coordinate convention, boundary
  bookkeeping, occupancy/support topology, divergence-free circulation, gauge/sign choice, eligibility conditioning,
  discretization, normalization, and oracle circularity.
- Ask what would falsify each interpretation and whether that falsifier exists in the allowed evidence.
- Treat DEV-only evidence as development evidence. No independent replication claim is available without an
  untouched prospective split, and held-out content is outside this mission.
- Audit the words `forced`, `minimal`, `native`, `canonical`, `flux`, `transport`, `topological`, `causal` and
  `necessary` separately. Each needs an operationally distinct witness.

### F. Roadmap

- Produce at least three routes: conservative consolidation, decisive falsification, and instrument/provenance
  repair if a load-bearing gate fails.
- For every route state eligibility, new information gained, dominant false-positive and false-negative risks,
  stopping rule, and what is explicitly not authorized.
- Do not invent a new scientific direction merely to keep the programme busy.

## Frozen contradiction criteria

Any one of the following is sufficient to fail the dependent claim:

- the independent reduction disagrees outside the frozen float64 criterion;
- a PASS gate cannot be made to fail on a valid adversarial construction;
- report totals cannot be reproduced from allowed raw rows;
- a denominator depends on the measured outcome without being declared;
- the oracle imports expected verdicts, expected totals or the report it grades;
- the same observable is used as both construction label and independent truth;
- claimed topology changes under an allowed coordinate or row-order symmetry;
- claimed flux is only a sign convention or boundary bookkeeping identity;
- claimed minimality has no tested smaller alternative;
- a local-only commit/report is described as public or reproducible without a bundle/archive;
- a push workflow can launch an outcome-generating scientific workflow.
