## 3. Audit findings accepted as standing obligations

The following three findings are **accepted as obligations and deliberately left unfixed**. They are
recorded here so that no later reader mistakes the qualified primitive for installed infrastructure.

1. **The lifecycle primitive is currently unused by real runners, so current `COMPLETE` paths remain
   bypassable.** Nothing imports it except the package re-export and its own test module.
2. **A caller can directly construct the exported lifecycle dataclasses containing a nominal
   `QUALIFIED` disposition without having run the validator.** Direct construction plus canonical
   serialization yields a well-formed document that never passed validation.
3. **The published JSON Schema is looser than the implementation and must not be treated as an
   independent validator.** It does not encode every constraint the implementation enforces.

In addition, the **known rejection of the generic empty-right-frame plus non-unit-cadence path is
retained**. That rejection is the correct present behaviour and must be preserved.

`instrumentation.py` and the schema are **not** repaired in this mission. Either change would alter
material bound by `FUTURE_LIFECYCLE_CONTRACT_00_QUALIFICATION.json` and would require separately
authorized requalification.
